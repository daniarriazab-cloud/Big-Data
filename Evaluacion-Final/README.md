# Evaluación Final – Curso Big Data

## Descripción del proyecto

Análisis de los tiempos de tramitación de proyectos habitacionales DS49 del SERVIU Metropolitano, desde la obtención del Certificado de Proyecto Ingresado (CPI) hasta su envío al Departamento de Obras (DOE).

El estudio utiliza estadística descriptiva y regresión lineal múltiple para explorar factores asociados a la duración de la tramitación y evaluar la capacidad predictiva de los modelos. Sus resultados se interpretan con fines de análisis de gestión y no como plazos comprometidos.

## Fuente de datos

Base preparada a partir de la planilla de seguimiento de proyectos DS49 del Departamento de Estudios del SERVIU Metropolitano, actualizada al **13 de noviembre de 2026**.

- [Base de datos: Base DS49_CPI_DOE.csv](Base%20DS49_CPI_DOE.csv)
- [Notebook: Arriaza_Daniela_Evaluacion_Final_BigData.ipynb](Arriaza_Daniela_Evaluacion_Final_BigData.ipynb)

## Cómo ejecutar el análisis

1. Abrir el notebook `.ipynb` en [Google Colab](https://colab.research.google.com/).
2. En Colab, seleccionar **Entorno de ejecución → Ejecutar todas**.
3. El notebook carga los datos directamente desde este repositorio de GitHub mediante una URL, sin necesidad de descargarlos ni configurar rutas locales.
4. Revisar las salidas, gráficos, interpretaciones y conclusiones incluidos en el notebook.

## Herramientas utilizadas

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn y Statsmodels.
